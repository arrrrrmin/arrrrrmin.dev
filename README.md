# arrrrrmin.dev

A personal lab/blog site on data wrangling and visualizations plus adjacent interests.
Site is diven by [Observable Notebook Kit](https://observablehq.github.io/notebook-kit/kit), 
most vis are SVGs build through js using [d3js](https://d3js.org).

Content includes:
- Basic charting principles
- Interactive data vis
- Reverse engineering of DDJ pieces
- Data backed news coverage
- Visualised data as UI elements
- Weird or fun experiments

Data preperation and wrangling included at [dataworks](https://github.com/arrrrrmin/arrrrrmin.dev/tree/main/dataworks).
