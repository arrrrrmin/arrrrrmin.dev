# Data works

A collection of data preperation scripts. Mostly working with duckdb. 
The data itself is not included in this repository. 
Transformations on the original data are only done to provide more effective formats used in frontends.
This collection is included so all data works are replicatable.

## Data used

### Our world in data

1. [CO2 emissions per capita](https://ourworldindata.org/explorers/co2.csv?v=1&csvType=full&useColumnShortNames=true&Gas+or+Warming=CO%E2%82%82&Accounting=Territorial&Fuel+or+Land+Use+Change=All+fossil+emissions&Count=Per+capita)
2. [GDP per capita (via worldbank)](https://ourworldindata.org/grapher/gdp-per-capita-worldbank.csv?v=1&csvType=full&useColumnShortNames=true)
3. [Gloabl temperature anomalies](https://ourworldindata.org/grapher/annual-temperature-anomalies)
4. [Life expectancy per country](https://ourworldindata.org/grapher/life-expectancy)
5. [Fertility per country](https://ourworldindata.org/fertility-rate)
